# AI-customer-feedback
This AI-powered Streamlit app analyzes customer feedback from CSV or Excel files - in any language - and provides instant sentiment analysis, AI-generated insights, and visual feedback summaries. It helps businesses, product teams, and analysts quickly understand how customers feel about their services or products without manual review.

CSV and Excel uploads support common feedback columns such as `feedback`, `review`, `text`, `tweet_text`, `full_text`, `content`, `comment`, and `message`. This lets [Xquik](https://xquik.com) exports be analyzed without renaming columns.
